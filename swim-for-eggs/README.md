# Swim for Eggs (Roblox)

An underwater "Steal an Egg"-style game: dive through 5 depth biomes, steal eggs, outswim Sea Monsters, and upgrade your Oxygen Tanks, Flippers and Egg Mutations.

- **[GUIDE.md](GUIDE.md)**: the full setup guide. It covers the Explorer hierarchy, terrain water, the depth zones and monsters, shops, aquarium barriers, the palette, the UI tree, the gameplay systems and monetization.
- `src/`: copy-paste-ready Luau scripts. Each file header says exactly where it goes in the Explorer.
- `default.project.json`: Rojo project (`rojo serve`).
